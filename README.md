# בדיקת חובות — Debts

אפליקציה נפרדת מ"ניהול הבית": בודקת חוב אצל ספקים (חשמל, ובהמשך מים/לימודים) עם קוד חד-פעמי שהספק שולח.
GitHub Pages + Supabase Free (אותו פרויקט וחשבון כמו ניהול הבית, טבלאות נפרדות). כתובת: https://meirbal.github.io/debts/

## מבנה
| קובץ | אחריות |
|---|---|
| `js/config.js` | גרסה, כתובת שרת |
| `js/api.js` | כל הגישה לשרת: התחברות (משותפת), משפחה (קריאה בלבד), `debt_checks`, הפונקציה |
| `js/providers.js` | טהור: רשימת ספקים, ספרת ביקורת ת"ז, מצב חוב, מתי להזכיר, קובץ תזכורות ליומן |
| `js/ui.js` | DOM, הודעות, חלונות, תאריך/כסף |
| `js/app.js` | כניסה, מסך ראשי, תהליך בדיקה (ת"ז → קוד → תוצאה), היסטוריה |
| `sw.js` · `manifest.json` · `icons/` | אפליקציה מותקנת, עבודה בלי רשת |
| `supabase/functions/debts` | שרת: התחברות לספק עם הקוד, קריאת חוב, שמירת תוצאה בלבד |
| `sql/` | מיגרציות (ממוספרות, לא עורכים קובץ שכבר רץ) |
| `tests/` | `node tests/logic.test.mjs` · `node tests/smoke.mjs` (דפדפן) · `deno run -A --node-modules-dir=none tests/function.test.ts ../supabase/functions/debts/index.ts` |
| `scripts/` | `release.sh X.Y.Z "הערה"` · `rollback.sh X.Y.Z` (ענפי `release/vX.Y.Z`) |

## ספק חדש
1. בשרת: אובייקט `Provider` (`start` שולח קוד, `verify` מחזיר `{total, items}`) ב-`PROVIDERS`.
2. בטלפון: שורה ב-`PROVIDERS` שב-`js/providers.js`.

## פרטיות ואבטחה
- ת"ז, קוד וטוקן של הספק לא נשמרים ולא נכתבים ללוג. נשמרת רק התוצאה (`debt_checks`, רק בני המשפחה רואים).
- מכסה אטומית (`take_debt_quota`): 5 שליחות קוד ו-15 אימותים ליום למשפחה, ותקרה כללית — הקודים הם SMS אמיתיים מכתובת שרת משותפת.
- ת"ז נשמרת בטלפון רק אם מסמנים "זכור".
